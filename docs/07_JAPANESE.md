# Japanese / JLPT plan
Updated 10 Oct 2026. Budget: **20 min every day** (≈2.3 h/week). Not registered for JLPT Dec 2026 — registration for the December test generally closes in Aug–Sep, so target **JLPT July 2027** (first Sunday of July). Call JUAAB (Dhaka test organiser) in Feb 2027 to get the exact July application window; registration usually opens ~3–4 months before the test.

## Goal
Rebuild from "forgot many things" → solid N5 by end of Dec → N4 level by April → sit **N4 in July 2027** (switch to N3 only if April mock ≥ 70%). Side goal: a clean 1-minute 自己紹介 (self-introduction) for Japan interviews by 31 Oct.
